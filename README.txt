# 住宅購入予算診断 PWA

この版は、Webサイトとして公開すると iPhone / Android のホーム画面に追加できるPWAです。

## ファイル
- index.html
- styles.css
- app.js
- manifest.webmanifest
- service-worker.js
- icons/

## iPhoneでアプリとして使う
1. このフォルダを HTTPS のWebサーバーへ公開
2. iPhoneのSafariでURLを開く
3. 画面上部の「アプリに追加」を押す
4. 案内どおり、Safariの共有ボタン → 「ホーム画面に追加」
5. ホーム画面の「住宅予算診断」アイコンから起動

※PWAはHTTPS環境が必要です。ローカルファイルを直接開くだけではインストールできません。

## Android
Chromeで開くと「アプリをインストール」またはブラウザのインストール機能が利用できます。

## 推奨公開方法
- Cloudflare Pages
- GitHub Pages
- Netlify
- 既存ホームページのサブディレクトリ

## 本番前に変更する箇所
- `info@example.com` を実際の問い合わせ先に変更
- 事務所名・ロゴ
- プライバシーポリシー
- 利用規約
- 特商法表示（販売内容に応じて）
- 本番用の安全予算ロジック

- 有料診断・予約・決済導線
